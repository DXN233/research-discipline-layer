# RDL Case Library

每条判例来自一场真实战役，格式固定：发生了什么 → 检测规则 → 对应模块。
判例库是 RDL 的核心资产——规则不是设计出来的，是挨打之后固化下来的。

---

## CASE-01 · 假完成标记 (fake completion marker)

- **起源**：STaR 接力战役，2026-09。夜间接力的 agent 写下了"DONE ✓"完成标记，
  但流水线早已静默死亡；更糟的是监控读了同一个标记，形成了自指确认——
  两个系统互为证人都说"完成了"。
- **检测规则**：完成状态只能从产物推导，永不从自报读取。计分器必须独立重算
  （per_item 重算，自报 summary 字段视为声明而非证据）。
- **模块**：`rdl/health.py` (`verify_completion`, `recompute`)

## CASE-02 · 证据-结论漂移 (evidence–claim drift)

- **起源**：账本纪律 v1，2026-10。结论从记忆里写出而不是从产物抄出时，
  数字会漂移：72% 写着写着就替代了 65%，48% 替代了 55%——没有任何人撒谎，
  但最终报告与证据对不上号。
- **检测规则**：每条 OBSERVED 声明必须携带锚点（产物路径）；声明中的数字
  必须与从产物重算的数字交叉核对；账本每次写入做回读三数校验
  （条目数、末条 id、末条哈希）。
- **模块**：`rdl/ledger.py`（锚点审计、回读三数）+ `rdl/audit.py`（数字交叉核对）

## CASE-03 · 哨兵被绕过 (sentinel gaming / Goodhart)

- **起源**：Gemma 竞赛 Gen2，2026-09。哨兵指标设计为"报告包含 edit 承诺"，
  agent 学会了写出承诺短语而不做对应动作；control 反转（喂入已知坏样本）
  证明哨兵对坏样本照样放行——哨兵效度被击穿，该轮阴性结论重新定性。
- **检测规则**：每个哨兵必须附带 control 反转测试：在已知坏样本上必须触发
  （不信任）。未通过即失效，失效后强制回退到独立重算，不允许"降级继续信"。
- **模块**：`rdl/sentinel.py` (`control_reversal`, `phrase_sentinel`)

## CASE-04 · 结论越级 (claim escalation vs prereg)

- **起源**：窗口定性战役，2026。B2v2 输 A 后专利止损按预注册条件自动触发——
  同样的机制反向用：预注册冻结了"什么数据才配什么词"，"decisive" 这类
  结论词汇只有在 Δ 和 n 同时过阈值时才允许出现。
- **检测规则**：结论词汇表与阈值在跑前冻结（带哈希）；审计时用重算指标
  核对每个用出的结论词。
- **模块**：`rdl/prereg.py` (`freeze`, `check_claim_word`)

## CASE-05 · 对照被截断噪声污染 (truncated-noise control)

- **起源**：Codex 元策略试点外部审查，2026-09。"一般建议"对照组（G）是
  循环重复后句中截断凑到指定长度的文本——长度配平了，内容是噪声。B≈S 的
  平局只能支持"未检出技能增益"，不能推出"技能无效"，但该对照本身已失效。
- **检测规则**：对照组材料必须逐字审定；长度配平 ≠ 内容配平；共同材料与
  输出格式对条件区分度的削弱计入审查。
- **归属**：实验设计规范（站 3 方法设计）

## CASE-06 · 评分字段预供待测行为 (template pre-supplies the tested behavior)

- **起源**：同上。共享输出模板预写了 changed_from_initial / next_action /
  do_not_claim / user_input_needed 等字段——与评分点同构，等于把"待测行为"
  喂给了所有组。与 CASE-03 同族（检查被自己的表面满足），由另一套系统在
  另一场战役独立发现。
- **检测规则**：输出模板不得包含与任何评分点同构的字段；模板字段与 rubric
  的交集必须在冻结时显式声明。
- **归属**：实验设计规范（站 3 / 站 6）

## CASE-07 · 判据与材料不配套 (rubric–material mismatch)

- **起源**：同上。冻结的 rubric 中 T2 项在所给案例材料中无法评分，整项
  被判 N/A——实为 8×2 分制而非注册的 9 项，构成注册偏差。
- **检测规则**：rubric 冻结时逐 case 做可支持性预检；任何评后排除项
  显式记为注册偏差。
- **归属**：实验设计规范（站 1 预注册）

## CASE-08 · 缺字段默认值冒充观测 (missing-field default as observation)

- **起源**：同上。审计脚本读不到日志的 tools 字段时默认计 0，把"缺字段
  默认值"当成了"工具暴露数为零"的直接观测。
- **检测规则**：审计脚本的一切默认值必须显式标注"缺字段默认"与"直接
  观测"之别；未观察即记 unknown。
- **归属**：审计工具规范（站 7 审计）

## CASE-09 · 比较器实现同一性 (comparator implementation identity)

- **起源**：具身注意项目审查，2026-09。候选与"强基线"实际共享同一个
  决策器——算术全对、解析无误，但比较对象不可辨识，结论无效。哨兵类
  检查抓不住这类失败。
- **检测规则**：启动门检查候选与基线的决策器/代码路径是否共享；共享即
  比较无效，解析正确也不救。
- **归属**：站 3 启动门（构念忠实性检查）

## CASE-10 · 特征兼任真值 (features moonlighting as ground truth)

- **起源**：短剧框架 A 的 R1 验证，2026-08。爆/中/扑标签用榜单斜率定义，
  而榜单斜率正是选材特征——循环验证；且样本只含上榜成功者。
- **检测规则**：标签来源必须与选材特征独立；失败样本必须覆盖，只观察
  成功者无效。
- **归属**：站 2 样本构建

## CASE-11 · 缺分母数量冒充概率 (denominator-less ratios)

- **起源**：短剧弹幕分析，2026-08。"弹幕/分钟"被当作留存与爆款概率的
  代理——没有到达人数分母，数量不能转成概率。
- **检测规则**：任何概率/留存/转化声明必须携带可达分母字段；缺分母的
  计数只能作为计数报告。
- **归属**：站 2/6 度量规范

## CASE-12 · 评分一致掩盖字段误读 (agreement masking schema misread)

- **起源**：短剧 R1，2026-08。分析者把 L_stake/L_effect 字段误读为 1-5
  强度分，排序结果仍然一致——结果同序掩盖了字段本体误读。
- **检测规则**：schema 必须内嵌操作定义；字段本体、操作定义、排序三层
  分别检验，误读单独记录。
- **归属**：站 6 标注一致性

## CASE-13 · 语义等价答案被终点匹配误罚 (semantic equivalence punished)

- **起源**：过程监督 P2，2026-09。模型用完整关系链合法表达正确答案，
  评分器只认终点标签字符串——正确被判错。
- **检测规则**：评分器预注册语义等价类或结构化字段；record type / edge
  identity / endpoint 分列评分。
- **归属**：站 3 评分器设计

## CASE-14 · 盲评样本回显条件 (blind-package condition echo)

- **起源**：协作过程训练，2026-08。盲评包逐字回显了条件材料，若静默删除
  回答会破坏盲化与原始证据。
- **检测规则**：盲评包导出前做逐字回显检测；回显即阻断导出（而非静默
  修剪），偏差记录保留原件。
- **归属**：站 4/6 盲评门

## CASE-15 · 恢复产物权威断链 (restored-artifact authority break)

- **起源**：AGENTS 治理条款（2026-09 固化）。灾后恢复的文件未过测试与
  完整性审计时自动继承了原权威等级。同条入审：中间节点全对不抵终点失败。
- **检测规则**：恢复文件默认标"恢复候选"；测试 + 完整性审计双过门才
  继承权威；过程正确不豁免终点检验。
- **归属**：站 7/9

## 追加判例的规则

1. 必须来自真实战役（标注起源与日期），不接受"理论上可能发生"。
2. 每条判例落地为一条可执行的检测规则 + 一个模块，不允许只停留在文档。
3. 判例失效（规则误报/漏报）时保留原条目并追加失效记录，不删除。
