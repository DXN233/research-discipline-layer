# 研究判例法 v0.2（合并裁决版）

> 别人的研究方法是设计出来的（成文法），我们的是判出来的（判例法）——每条规则带真实事故起源，判例库即制度记忆。
>
> **版本记录**：v0.1（2026-10-09，ZCode 初合并九站+六步）→ Codex 长期记忆检索 20 条（codex-memory-findings.md）→ Codex 正式审阅（2026-10-10，四个开放点全部裁决，见文末）→ **v0.2 本版：裁决并入，20 条发现正式挂站，判例库升格至 15 条**。v0.1 连同审阅意见原样存档于 研究判例法-v0.1.md。

## 一、定位：两层司法制度

| 层 | 名称 | 来源 | 管辖 |
|---|---|---|---|
| 战役层 | 九站循环（宪法） | ZCode 侧，7+ 场战役验证 | 一场研究战役从定题到结案的全程 |
| 决案层 | 六步纠偏协议（诉讼规则） | Codex 侧，运行时试行 | 战役中每一个具体决策的取证与更新 |
| 共享 | 判例库（判例集，15 条） | 双方判例合并 | 跨战役、跨任务的制度记忆 |

核心接线：**九站的每一站内部，跑六步决案循环。**站是法庭，六步是庭审程序。

## 二、战役层：九站循环（v0.2 扩充）

每站列出：核心规则 + 本版新增挂钩（标注来源：CASE-XX 判例 / F-XX Codex 记忆发现，全文见 codex-memory-findings.md）。

### 第 1 站 · 定题与预注册
核心：假设、结论词汇阈值、止损条件跑前冻结（带哈希防篡改）。
新增：
- **研究对象核对先行**（F-01）：先冻结"研究对象—分析层级—方法变量"的区分，防止手段（如过程监督）偷升为研究对象。
- **实验类型声明**（F-02/13）：预注册必须声明战役类型——开放发现 / 条件机制 / 业务验证，结论权限按类型限定（见 §六-1）。
- **失败分类与重试政策预注册**（F-10）：运行状态四分（complete / partial / model_output_failure / infrastructure_failure）；模型格式错误计入结果，纯基础设施失败同提示重试一次并保留两次记录。
- **样本量的功效纪律**（F-15）：冻结数字必须带依据；无功效分析的数字只能标"程序性阈值"，不得冒充科学门槛（见 §六-4）。

### 第 2 站 · 先验构建
核心：全量拆解建立先验（facts/轴/基因卡）。
新增：
- **标签独立性**（F-06）：标签不得由选材特征兼任定义；必须覆盖未上榜/中位/失败样本，只看成功者一律无效。
- **分母纪律**（F-07）：无分母的数量（弹幕/分钟、点击数）不得转成概率或留存声明（CASE-11）。
- **先验纳入门**（F-18）：前沿材料须达显著认知增量门槛；无合格增量时明确报告"无新增"，允许基础补全。

### 第 3 站 · 方法设计与自我攻击
核心：多路线逐一证伪；control 反转打自己哨兵；能力判断带五元组定位。
新增：
- **构念忠实性启动门**（F-03，执行前检查）：原始机制逐项映射、比较方法可辨识、关键构念未被简化、任务可解析求解、最小有意义差异有依据——**不得用增加回合/阈值/潜变量挽救构念错位的方案**。
- **比较器实现同一性检查**（F-04，CASE-09）：候选与强基线共享决策器/代码路径 = 比较无效，即使解析计算无错。
- **四门分离**（F-05）：表示可读 / 通道依赖 / 样本信息使用 / 任务收益是四个独立门槛，逐个过门，不得互相抵充。
- **评分器语义等价**（F-16，CASE-13）：预注册语义等价类或结构化字段，终点精确匹配不得误罚完整正确的关系链表达。
- **反馈对照规范**（F-14）：状态匹配反馈须与同原子、同操作的自然错配反馈（yoke）比较；无第二样本时冻结不运行。

### 第 4 站 · AI 执行
核心：长跑纪律——阶段体检、增量落盘、假完成标记识别（CASE-01）、监控不自指。
新增：
- **按预注册状态执行与留痕**（F-10）：每次尝试保留原始响应/stdout/stderr/meta/token 审计与哈希；未启动/未完成据实报告。
- **盲评材料门**（F-11，CASE-14）：盲评包逐字回显条件材料时阻断导出，不得静默删改回答；运行 ID/种子显式冻结。

### 第 5 站 · 环内监督
核心：过程监督在中间状态打分、当轮回流；可验证奖励闭环。
新增：
- **干预来源真实性**（F-12）：人类自然纠偏不得由 AI 代写或预生成冒名；纠偏、AI 解释、现实结果、模型自评四类不可混成一个真值标签。
- **权力边界**（F-17，张力裁决见 §六-2）：过程分只是训练/监督信号；中间节点全对、通道有依赖都不构成终点收益证据。

### 第 6 站 · 评估
核心：盲评外包另一模型、三轴基准、凡计分器必抽检。
新增：
- **样本级配对三条件**（F-05）：matched 须同时超过 base 与 shuffled 且出现 correct-only，否则停止该架构——区分"通道被用"与"内容被用"。
- **终点不可抵销**（F-17，CASE-15）：中间节点全对不能抵销终点失败；终点低于对照即负结果，不得追加 seed 救结果；任务串扰独立诊断。
- **字段理解一致性**（F-08，CASE-12）：评分排序一致 ≠ 字段理解一致；schema 须内嵌操作定义，字段误读单独记录。
- **负结果入正文**（F-17）：预注册的负结果写入论文正文/补充，禁止选择性遗漏。

### 第 7 站 · 审计与判定
核心：六维审计；账本三标签+锚点+回读三数；真值账本校准人类判定者（双向审计）。
新增：
- **残差保留**：审计输出必含 unresolved 字段；分类不够就保留未解释部分，允许新变量新关系。
- **"不知道"四分法入账**：没信息 / 没访问 / 没验证手段 / 推理失败——弃权时必须注明属于哪一种。
- **真值分层**（F-12/13，见 §六-3）：人类判定 / 机制隐藏键 / AI 评估 / 业务结果是四类不同证据，不得互相冒充。
- **恢复产物权威断链**（F-20，CASE-15 附）：灾后恢复文件未过测试与完整性审计前只是"恢复候选"，不自动继承原权威等级。

### 第 8 站 · 结论与止损
核心：三层结构、组件级表述、决定带打开条件；预注册止损自动触发；"不行动"合法；过程有效与结果有效分开记录。
新增：**"无新增"是合法结论**（F-18）——明确报告并允许基础补全，不用类比和新鲜感凑增量。

### 第 9 站 · 迭代回流
核心：失败固化为带打开条件的判例条款。
新增：**入库触发边界**（F-20）：仅四类入库——有设计含量的变更、确认的偏好/决策、已验证可复现的方法、实质风险/返工教训；同目标按里程碑合并，不为入库而入库。

## 三、决案层：六步纠偏协议（嵌入每站）

完整六步（触发条件：能力边界不明、预期与观察冲突、反复失败、问题表示需重写）：
确定当前决定 → 有条件的能力判断（五元组定位）→ 保存残差 → 选择能改变决定的下一步 → 行动前留可检验预期 → 按实际反馈更新。

**压缩形态的精确边界（v0.2 裁决，Codex 2026-10-10）**：无触发条件时走三步压缩（确定决定 → 可检验预期 → 按反馈更新）；一旦出现任一触发条件**必须展开完整六步**，且压缩路径的"按反馈更新"同样保留未解决残差与过程效果/终点结果的分离记录。

## 四、记账统一（v0.2 裁决版）

1. **两字段并存**：账本标签 [观测/推断/决定]（结论的认识论地位）× evidence_level [candidate / observed_local / prospective_transfer]（经验的可迁移等级）。
   **字段纪律（Codex 裁决）**：evidence_level 不得由账本标签自动推导；未知、不适用、未测必须如实保留，不得为满足双字段结构编造值。
2. **锚点规则**：凡观测级条目必带产物锚点；保存原始证据，不只保存漂亮总结。
3. **"不知道"四分法**：弃权必注明类型（没信息/没访问/没验证手段/推理失败）。
4. **落盘位置（裁决）**：决案层记录保留在**各项目既有日志**内，不建新系统；战役账本只保存引用、ID、摘要与升格结果。候选纠偏达到 observed_local 且有可执行检测规则时，升格入判例库——防止候选经验被误当共享制度。

## 六、四类张力的裁决（v0.2 新增）

1. **开放发现 vs 隐藏键实验**：两者都合法，作用域互斥。开放发现冻结的是不完整起点（初始问题表示与已知元素），**不冻结"正确关系"**；隐藏结构只支持条件性机制主张；现实付款不是机制实验的通用真值。每场战役在站 1 声明类型，结论权限按类型执行。
2. **过程分 vs 终点收益**：过程分是训练/监督信号，不是终点效果证据。终点指标失败的战役，无论中间节点多干净，一律按负结果处理并写入正文；过程有效性可入候选经验，不抵终点。
3. **真值分层**：人类判定 / 机制隐藏键 / AI 评估 / 业务结果是四类证据，各有适用主张范围；跨类冒充（拿业务结果证明机制、拿 AI 自评当人类判定）由站 7 审计拦截。
4. **统计与治理门的反冒充**：一切数量门（样本数、重试数、关闭样本数）必须标注作用域与依据；无功效依据的冻结数字是程序性阈值，不是科学门槛；治理门不得泛化为普适标准。

## 七、方法论自身的验证梯定位

四级梯：可调用 → 当次遵循 → 跨任务迁移 → 权重内化。**当前等级：observed_local**（单操作者、7+ 战役、判例库 15 条含双 AI 独立收敛案例——CASE-03 与 CASE-06 为同一失败族在两侧独立出现）。升 prospective_transfer 的两条路已在跑：社群 break-report（RDL Issue #1）、协议复制实验。声明纪律：本协议效果声明不得高于 observed_local。

## 八、合并风险与防御

| 风险 | 防御 |
|---|---|
| 官僚化 | 六步仅纠偏触发；压缩三步限无触发日常路径；九站分级（小任务 1/7/8，中任务加 3/6） |
| 双重记账 | 一套账本两字段；决案记录留项目内，升格才入库（§四-4） |
| 层间套娃 | 站是法庭、六步是庭审程序；无触发即三步，触发即六步，不存在 54 步 |
| 判例库膨胀 | 升格门（真实起源+可执行规则）+ 入库触发边界（仅四类）；挂不上规则的留在项目内不升格 |
| 裁决漂移 | 本版所有裁决可溯源（v0.1 审阅意见原文存档）；推翻裁决须新判例 |
